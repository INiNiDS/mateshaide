# Hotkeys

### Tools

- T: Text tool. E: Eraser. Ctrl + 8: toggle the eraser. Ctrl + 9: toggle drawing.
- Escape: leave the eraser or a tool; while typing it finishes the text block.
- F1: open or close this help.

### History and files

- Ctrl + Z: undo. Ctrl + Y or Ctrl + Shift + Z: redo.
- Ctrl + S: save the document. Ctrl + O: open a document.
- Ctrl + E: export PNG. Ctrl + P: export PDF.

### View

- Ctrl + = or Ctrl + numpad +: zoom in. Ctrl + - : zoom out. Ctrl + 0: 100%.
- Mouse wheel: pan; Ctrl + wheel: zoom; right or middle button drag: pan.

### Plugins

- Ctrl + Shift + P: the Plugins page. F5 on that page: rescan plugin folders.

### While typing in a text block

- Ctrl + A, Ctrl + C, Ctrl + X, Ctrl + V: select all, copy, cut, paste.
- Shift + letter: superscript. Ctrl + letter: subscript.
- Enter: new line. Tab: four spaces. Arrows, Home, End: move; add Shift to select.
