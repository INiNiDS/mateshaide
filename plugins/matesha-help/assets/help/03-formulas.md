# Formulas

The Text tool turns plain typing into 2D math as you type.

### Superscripts and subscripts

- x^2 or x^{n+1}: superscript. Braces group several characters.
- x_i or x_{i,j}: subscript.
- Shift + letter right after a character types it as a superscript: Shift + N after x gives x to the power n.
- Ctrl + letter types a subscript.

### Big operators and limits

- Type sum, prod, int, iint, oint: they become the symbols with the same names.
- Limits use the same syntax: sum_{i=1}^{n} puts the limits below and above the sum.
- For integrals the limits go to the right side: int_0^1 x dx.

### Fractions and roots

- a//b makes a fraction with a over b. Use parentheses or braces for longer parts: (a+b)// (c+d).
- sqrt{x} or the symbol from sqrt draws a square root over the group.

### Brackets

- Typing { inserts a pair {}; typing } before an automatic } just steps over it.
- Braces are structural: they group and are hidden in formulas. To show a literal brace type a backslash first: \}
  or \{.
- Round and square brackets are ordinary characters.

### Symbols

- Words: alpha, beta, gamma, delta, theta, lambda, mu, sigma, omega, pi, inf, nabla, partial, forall, exists, pm, cdot,
  times.
- Pairs: <= gives less-or-equal, >= greater-or-equal, != not equal, -> arrow, => implies, +- plus-minus.
