# MateshaIDE overview

MateshaIDE is an infinite canvas for math: you draw, write text and 2D formulas, and export the result to PNG or PDF.

### The screen

- Top toolbar: Plugins, Open, Save, Draw, Eraser, Text, Undo, Redo, zoom (-, 100%, +), PNG and PDF export.
- Top right: Dark and Halloween themes.
- Under the toolbar: tool buttons and quick commands of active plugins (colors, font size, fonts, Help, Auto-Save).
- Bottom: a notice line with messages and errors.

### Moving around

- Mouse wheel: pan. Ctrl + wheel: zoom at the cursor.
- Hold the right or middle mouse button to drag the canvas.
- Ctrl + 0 resets the view to 100%.

### Files

- Save (Ctrl + S) writes the whole canvas into a .json document; Open (Ctrl + O) loads it back.
- PNG (Ctrl + E) and PDF (Ctrl + P) export everything that is on the canvas.
