# Text tool

Text and formulas live in text blocks of the Text Editor plugin (org.matesha.text). Activate it once on the Plugins
page.

### Creating a block

- Press T or the Text button, then click an empty place: a caret appears right there. The block is created by the first
  typed character.
- Double-click an empty place on the canvas (when Draw and Eraser are off) to start a block there.
- Escape or a click outside finishes editing. An empty block is removed.
- Undo (Ctrl + Z) removes a block you have just created.

### Editing

- Click inside a block to place the caret; drag to select; Shift + click extends the selection.
- Arrows, Home, End move the caret; with Shift they select.
- Ctrl + A selects all, Ctrl + C / Ctrl + X / Ctrl + V copy, cut and paste.
- Enter starts a new line, Tab inserts four spaces.

### Moving and resizing

- Drag the thin bar above a selected block to move it.
- Drag a corner handle to resize: the font size follows the block size.

### Look

- Quick commands: Ink, Blue, Red, Green set the color; A- and A+ change the size.
- Font > switches to the next font, Font... loads a .ttf or .otf file (see "Fonts").
